# Проект по автоматизации тестирования (Урок 10)

В данном разделе представлены авто тесты для «Медленного калькулятора» и магазина «SauceDemo» с применением паттерна **Page Object** и отчетности **Allure**.

## Инструкция по запуску

### 1. Формирование результатов тестирования
Для запуска тестов и сбора данных в папку `allure-results` выполните команду из корня проекта:
```bash
pytest --alluredir=allure-results " lesson_10/"

### 2. Просмотр сформированного отчета
Для генерации графического отчета из собранных данных и его открытия в браузере выполните команду:
```bash
C:\allure\bin\allure.bat serve allure-results
